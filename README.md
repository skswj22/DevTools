# DevTools 🛠️

개발 생산성 향상을 위한 경량 유틸리티 및 AI 스킬 모음 저장소.

- **경량 도구 (Vanilla JS)**: 별도 설정 없이 즉시 활용 가능한 단일 파일 유틸리티
- **AI 스킬 (AI Skills)**: 멀티 에이전트 조율 및 협업 규약

## 🧰 도구 (Tools)

순수 자바스크립트 기반 경량 유틸리티. 복잡한 설정 없이(Zero Configuration) 즉시 사용 가능.
- [도구 목록 보기](./tools/README.md)

## 🤖 AI 스킬 (AI Skills)

자주 사용하는 AI 스킬 모음. 각 스킬은 폴더 단위 관리 및 `SKILL.md`로 정의.
- [스킬 목록 보기](./skills/README.md)
