# HandyUtils (핸디 유틸) 🛠️

**HandyUtils**는 개발자에게 유용한 것들을 모아두는 저장소.<br/>
바로 가져다 쓸 수 있는 경량 도구(Vanilla JS)와, 자주 쓰는 AI 스킬(AI Skills)을 함께 모음.

## 🧰 도구 (Tools)

순수 자바스크립트 기반의 경량 유틸리티. 복잡한 설정 없이(Zero Configuration) 바로 사용 가능.

### 1. [LiteGantt](./tools/lite-gantt)
초경량 순수 자바스크립트 간트 차트 라이브러리.
- **특징**: 의존성 없음, 자동 무지개 색상, 반응형 디자인.
- **용도**: 경력 기술서, 프로젝트 일정, 로드맵 시각화.
- [자세히 보기](./tools/lite-gantt/README.md)

### 2. [LiteToast](./tools/lite-toast)
의존성 없는 초경량 토스트 알림 라이브러리.
- **특징**: CSS 자동 주입, 4가지 테마(Success, Error, Warning, Info) 지원.
- **용도**: 웹 어플리케이션 알림, 사용자 피드백.
- [자세히 보기](./tools/lite-toast/README.md)
