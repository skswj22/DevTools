## 완료/실패 보고 (필수 — 아래 명령 중 해당 사항 즉시 실행)
- **성공**: `orca terminal send --terminal <report_to> --text "<on_done>" --enter --json`
  (헤더 `final: true` 설정 시 `--text` 값을 `"완주"` 로 변경 전송)
- **실패·중단**: `orca terminal send --terminal <report_to> --text "<on_fail>: <한 줄 사유>" --enter --json`

> 주의 규칙: 완료 기준(DoD) 미충족 또는 승인 대기·에러 발생 시 **임의 대기 금지 및 실패 신호 즉시 전송 필수** (미보고 시 조율자 대기 상태 지속 및 파이프라인 중단).
