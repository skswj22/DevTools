# AI 스킬 (AI Skills) 🤖

자주 쓰는 AI 스킬 모음. 각 스킬은 폴더 하나로 관리하며, 폴더 안의 `SKILL.md`가 스킬을 정의함.

## 구조

```
skills/
└─ <skill-name>/
    └─ SKILL.md   # 스킬 정의 (frontmatter: name, description)
```

## 스킬 목록

### [orca_co-op](./orca_co-op)
orca 데스크톱 앱(onOrca.dev) 안에서 나란히 실행되는 여러 AI 에이전트 pane을 조율하는 스킬.
- **용도**: 옆 pane에 작업 전달, 다른 에이전트에게 질문·답변 수신, 멀티 에이전트 릴레이(토큰링).
